## C# PDF

Hands-on tutorials and reproducible benchmarks for C# and .NET PDF libraries.

| Repository | What's in it |
|---|---|
| [pdf-libraries-compared](https://github.com/csharp-pdf/pdf-libraries-compared) | Per-library pages, the same set of compilable samples for every library, and topic tutorials |
| [pdf-benchmarks](https://github.com/csharp-pdf/pdf-benchmarks) | The benchmark harness, test fixtures and raw results — run it yourself |

**Disclosure:** this organization is maintained by [SelectPdf](https://selectpdf.com/),
which makes a .NET PDF library and an HTML to PDF API that appear in these
comparisons. Every number published here comes from code in these repositories
that anyone can run, and every vendor can submit corrections.
